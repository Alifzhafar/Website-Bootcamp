# Website Bootcamp / E-Learning

Project landing page untuk program bootcamp dan pembelajaran digital. Situs ini terdiri dari halaman utama, agenda, FAQ, dan kontak yang dirancang untuk menarik calon peserta agar mendaftar ke program belajar yang ditawarkan.

## Fitur

- Halaman beranda yang menjelaskan program utama
- Halaman agenda untuk informasi jadwal dan program
- Halaman FAQ untuk pertanyaan umum
- Halaman kontak untuk form dan informasi hubungi
- Desain responsif untuk desktop dan mobile
- Styling menggunakan Bootstrap dan custom CSS

## Cara Menjalankan

### Opsi 1: Buka langsung di browser

Buka file `index.html` secara langsung di browser favorit Anda.

### Opsi 2: Jalankan server lokal

```bash
cd "web bootcamp"
python3 -m http.server 8000
```

Lalu buka browser ke:

```text
http://localhost:8000
```
